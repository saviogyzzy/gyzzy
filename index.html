ANTES DE COMEÇAR

Informações claras, desde o início.

Funciona no Windows 7 ou em 32 bits?

Não. Esta versão usa runtime atual de 64 bits. No Windows, atende Windows 10 e 11 x64.

Preciso de internet para trabalhar?

As operações comerciais são locais e funcionam offline. Internet é necessária para acessar este site e baixar atualizações.

Como as atualizações chegam?

O aplicativo consulta manifestos assinados deste site e verifica o pacote baixado. No Windows, instala ao fechar normalmente. Linux e macOS usam instalação guiada do pacote verificado.

As lojas dos clientes ficam conectadas?

Não há sincronização de lojas nem acesso remoto pelo vendedor. Cada token comercial cria uma loja local; a equipe só participa da mesma loja quando convidada.

O sistema emite nota fiscal ou confirma Pix?

Esta versão serve para gestão interna. Não emite NF-e/NFC-e e não confirma pagamentos automaticamente. Recibos e orçamentos não substituem documentos fiscais.

Os pacotes para Mac estão prontos para venda?

Ainda são experimentais. Precisam de assinatura Developer ID, notarização Apple e testes em um Mac antes de uma oferta comercial. O sistema poderá bloquear a abertura do pacote sem assinatura.
