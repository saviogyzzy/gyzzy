GRYZZY V7.
Comece pelo seu acesso.

Os pacotes V7 foram gerados para Windows, Linux, Mac e Android. A publicação pública dos arquivos está sendo finalizada. iPhone/iPad ainda não têm aplicativo.

Android: já tenho conta

Ao reabrir uma instalação com conta salva, aparece Entrar na minha loja. Informe o usuário e a senha dessa instalação.

Em um aparelho sem conta salva, use Já tenho conta · Entrar / restaurar e selecione seu backup Android protegido. O cadastro do computador ainda não sincroniza com o celular.

Atualização da versão anterior

Faça um backup externo antes de atualizar. No Android, instale o APK V7 sobre a versão anterior, sem desinstalar nem limpar os dados. A V7 mantém a identidade do aplicativo e a chave de assinatura.

Os pacotes desktop preservam o nome e a identidade GRYZZY. Confira a atualização em uma cópia dos seus dados antes de usar em uma loja real. Os instaladores ainda precisam de homologação em cada sistema.

Tokens compatíveis

A V7 mantém o formato GRZ4, os 500 tokens da nova edição e as chaves públicas de verificação. Tokens novos não ativam a versão 6.0.0 antiga. O proprietário usa o token 001 e seu emissor privado para gerar novos códigos; tokens de cliente não permitem emissão.

Compra automática pelo Mercado Pago

O valor da licença é R$ 49,99 por instalação. O serviço foi implementado para consultar o pagamento e entregar o token após a confirmação. As vendas continuam desativadas enquanto a configuração e o teste oficial não forem concluídos.

O retorno do checkout sozinho não libera uma licença. Guarde o token e acesse o pedido no mesmo navegador usado para comprar. Ainda não há entrega por e-mail configurada.

Dados e cópias

Os dados ficam em cada aparelho. O Android usa armazenamento protegido e backup cifrado com senha. Backups do desktop não são importados no Android. Uma licença vinculada a uma instalação pode exigir uma nova emissão caso você troque de aparelho.

Esta edição Android inclui produtos, vendas, estoque, caixa, clientes, orçamentos e contas a pagar/receber. Não possui todos os módulos do desktop e não emite documentos fiscais.
